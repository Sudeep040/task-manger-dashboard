# Task Manager Dashboard

Bare Next.js scaffold with TypeScript and Tailwind configuration.

Getting started:

1. Install dependencies (this will install devDependencies including TypeScript and Tailwind):

```bash
npm install
```

2. Start dev server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

Notes:
- Tailwind is configured (see `tailwind.config.cjs` and `postcss.config.cjs`). Styles are imported from `styles/globals.css`.
- To run a type-check only: `npm run type-check`
